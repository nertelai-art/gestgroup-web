# Gestgroup — web

Web nova de [Gestgroup](https://www.gestgroup.es/), consultoria IT de Girona, feta per Nertel.
Next.js 16, Tailwind 4, castellà i català.

```bash
pnpm install --frozen-lockfile
pnpm dev
```

- `pnpm check`: typecheck, lint i proves (també és el hook de pre-push).

Context, contingut i decisions: [`CLAUDE.md`](CLAUDE.md), [`docs/fonts.md`](docs/fonts.md) i
[`docs/direccio-visual.md`](docs/direccio-visual.md).

Va començar com a demo privada per a Gestgroup; l'han acceptada (12-11-2026) i el kit de demo ja no hi
és. El pas al seu domini: [`docs/llancament.md`](docs/llancament.md).
